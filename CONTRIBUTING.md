# Contributing to Roam Control

Thanks for helping improve Roam Control.

Roam Control is currently maintainer-developed and is not accepting pull
requests or unsolicited code contributions.

## Issues and technical feedback

Bug reports, feature requests, detailed reproduction steps, testing results and
technical findings are very welcome through GitHub Issues.

If you have investigated a problem yourself, feel free to include anything you
have discovered that may help diagnose it. Detailed information about what you
expected, what actually happened, your Roam Control build and iOS version can
be especially useful.

Please do not include pairing records, credentials, signing material, private
location information or other sensitive data in an issue.

For security-sensitive reports, use GitHub Security Advisories rather than a
public issue.

## Pull requests

Roam Control is not currently accepting pull requests.

Development and implementation are handled by the project maintainer so that
changes can be designed, tested and integrated consistently with the existing
architecture and project roadmap.

Ideas and technical investigation are still welcome. Please open an issue
rather than implementing the change as a pull request.
