# StarFly 網路流程捷徑

StarFly 會執行名稱為「StarFly 網路流程」的個人捷徑，並傳入下列其中一個文字：

- `disable-cellular`：關閉行動數據。
- `enable-cellular`：開啟行動數據。

在 iPhone 的「捷徑」App 建立一個名稱完全相同的捷徑，並依序加入：

1. 加入「如果」動作，條件選擇「捷徑輸入」**是** `disable-cellular`。
2. 在「如果」區塊加入「設定行動數據」，設定為「關閉」。
3. 在「否則」區塊加入「設定行動數據」，設定為「開啟」。
4. 不要加入「停止此捷徑」或需要手動確認的動作；讓捷徑正常結束。
5. 在 StarFly 的「控制中心 → 捷徑流程」填入相同的捷徑名稱，並開啟「需要時自動執行捷徑」。

StarFly 以 Shortcuts 的 x-callback URL 執行此捷徑。捷徑完成、取消或失敗時，系統會返回 StarFly；App 隨即繼續偵測 LocalDevVPN 連線。

iOS 要求使用者在自己的裝置上建立與信任個人捷徑，因此 App 無法代替使用者安裝或修改該捷徑。部分電信商、MDM 管理設定或 iOS 版本可能讓「設定行動數據」動作無法使用；請先在捷徑 App 手動測試一次。
