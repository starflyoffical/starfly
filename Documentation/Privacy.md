# StarFly Privacy

StarFly has no StarFly backend connection. It does not verify license codes, download administrator-published routes, send anonymous usage statistics, or automatically upload diagnostic reports.

## Data stored on this iPhone

- Pairing records are stored in the device-only Keychain.
- Preferences, favourites, location history and saved routes are stored in local app storage.
- A GPX route is read only when you choose a file to import. StarFly does not upload that route to a StarFly service.
- Connection diagnostics remain in the app unless you explicitly choose to share the report using iOS's share sheet.

## Services required for app features

Apple MapKit provides maps, place search and route previews. Those features may send search or map requests to Apple; consult Apple's privacy information for how Apple handles that data. LocalDevVPN and Apple's iPhone pairing services are used for the local device connection. These are not StarFly account, license or route-management services.

## Changes

The app has no automatic StarFly data reporting. Any future network feature must be disclosed here and in the app before release.
